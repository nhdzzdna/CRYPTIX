# P3 — Header keamanan, CSP, dan JavaScript inline

## Yang diubah
- `app.py`: `after_request` menambahkan Cache-Control `no-store` + Pragma
  `no-cache` (kecuali `/static/`, tanpa menimpa nilai rute), `nosniff`,
  `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, dan CSP persis
  sesuai butir; berlaku juga untuk HTML error, 404/500, dan JSON.
- JavaScript inline/`on*` dipindah ke berkas terpisah + `addEventListener`:
  assistant→`assistant.js`, crypto_tools→`crypto_tools.js`,
  register→`register.js`, setup→`setup.js`, base (sidebar)→`script.js`,
  media_vault (konfirmasi hapus)→`media_vault.js`.
- `tests/test_registration_flow.py` disesuaikan memakai `js/setup.js`.

## Berkas
`app.py`, `templates/{assistant,crypto_tools,register,setup,base,media_vault,account_vault}.html`,
`static/js/{assistant,crypto_tools,register,setup,script,media_vault}.js`,
