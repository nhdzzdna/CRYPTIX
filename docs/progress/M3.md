### A. Penyisiran Teks & Istilah Pengguna (Butir 2)
1. **Passphrase**:
   - Seluruh label tampilan form telah menggunakan "Kunci rahasia".

2. **Musik vs Audio**:
   - Tampilan navigasi sidebar, judul halaman, dan dropzone telah konsisten menggunakan istilah "Audio".
   - Kata "musik" hanya tersisa pada nama rute kompatibilitas `/musik` (yang meredireksi 308 ke `/audio`) dan fungsi JavaScript internal `buatKartuMusik`.
3. **Upload vs Unggah**:
   - Seluruh teks aksi pengguna telah menggunakan istilah "Unggah".
   - Kata `UPLOAD` pada template hanya muncul sebagai nama blok aksi integritas audit blockchain, bukan teks antarmuka.
4. **Usb vs USB/Dongle**:
   - Konsisten menggunakan kapitalisasi standar "USB" atau "Dongle USB" pada seluruh templat dan string.
5. **Emoji**:
   - Ditemukan 1 emoji literal gembok (`🔒`) pada pembuatan elemen dinamis di `static/js/media_albums.js:177`.
   - **Tindakan**: Diganti menggunakan elemen SVG sprite `<use href="/static/icons/sprite.svg#lock"></use>` agar seragam dengan ikon grafis sistem.
6. **Kata Terlarang menurut `AGENTS.md`**:
   - Telah diverifikasi 0 temuan pada seluruh templat, kode Python, berkas JavaScript, CSS, dan konfigurasi.
7. **Pembersihan Jejak Debug**:
   - Tidak ditemukan `Security Assistant` pada templat, modul, maupun skrip aktif.
   - Tidak ditemukan status item bernilai `hidden` (kata `hidden` hanya digunakan sebagai atribut HTML murni `element.hidden = true/false`).
   - `TODO` dan `FIXME`: 0 temuan.
   - `console.log` di `static/js/`: 0 temuan.
   - `print(` debug pada `routes/` dan `modules/`: 0 temuan (hanya ada penamaan fungsi/variabel).
