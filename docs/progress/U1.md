# U1 — Halaman Autentikasi dan Dashboard

## Ringkasan

Sesi U1 memodernisasi antarmuka autentikasi (`auth_base`, `login`, `register`,
`recovery`, `account_recovery`, `setup`, `error`) dan halaman `dashboard` sesuai
fondasi token `--kx-*`, kelas `kx-*`, sprite ikon `_ikon.html`, dan API `KX`.
Halaman mengadopsi tata letak split untuk autentikasi dan kisi bento untuk dasbor,
menghilangkan elemen lama yang tidak relevan (termasuk panel status keamanan pada
dasbor dan tombol lama), serta menyelaraskan pengujian regresi.

## Keputusan Desain

1. **Penghapusan Panel Status Keamanan Dasbor**: Sesuai instruksi yang mengalahkan spesifikasi awal, panel status keamanan (dongle, WebAuthn, wajah) tidak ditampilkan di dasbor. Ruang dasbor difokuskan pada ringkasan aset, penggunaan penyimpanan, kondisi rantai integritas, dan log aktivitas.
2. **Peniadaan Subjudul dan Tombol Tambahan**: Subjudul deskriptif panjang, tombol unggah di topbar, tombol pencarian global, dan asisten keamanan ditiadakan pada kerangka halaman sesi ini.
3. **Status Dongle pada Halaman Masuk**: Badge status dongle diawali dalam kondisi tersembunyi (`hidden`) dan hanya dimunculkan setelah balasan API `/api/dongle/status` selesai diterima dari backend.
4. **Tautan Reset Akun**: Rute `/recovery/reset-account` belum tersedia pada kode utama, sehingga tautan tidak dipasang pada antarmuka pemulihan untuk mencegah tautan rusak.
5. **Penegakan Centang Simpan Kunci**: Penonaktifan tombol lanjut sebelum konfirmasi penyimpanan dilakukan pada sisi klien (`recovery.js`), serta divalidasi ulang di backend pada endpoint konfirmasi.
6. **Data Segmen Penyimpanan**: Karena backend saat ini hanya mengembalikan metrik agregat `total_bytes`, bar penyimpanan memetakan penggunaan berkas terenkripsi yang ada dengan legenda kategori yang telah disiapkan untuk pemetaan rincian lebih lanjut.

## Keterbatasan

1. **Rincian Ukuran per Kategori Penyimpanan**: Backend belum membedakan ukuran bita Dokumen, Media, Audio, dan Stego secara terpisah dalam kueri dasbor; saat ini ditampilkan total bita direktori penyimpanan terenkripsi dengan catatan pendukung bahwa rincian per jenis belum tersedia.
2. **Pendeteksian Mata pada Biometrik Wajah**: Pengecekan mata menggunakan Haar Cascade dan rasio citra ROI sederhana pada webcam klien, sehingga akurasi deteksi bergantung pada kualitas pencahayaan dan posisi kamera pengguna.
3. **Simulasi USB Dongle pada Lingkungan Non-Removable**: Deteksi drive penyimpanan bergantung pada `psutil` / mount point sistem operasi.
