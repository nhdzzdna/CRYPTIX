# N3b — Menu Musik dan Dokumen memakai koleksi N3a
- Audit: tabel `collections(kind)` + `collection_items(state)` sudah mendukung album/musik/dokumen; rute `/api/collections*` di collection_routes.py memakai user_id pemilik dan grant `album.unlock`.
- Audit: media_routes.py hanya bergantung pada kind='album' saat mengelompokkan galeri; audio sebelumnya dirender dari semua koleksi. media_albums.js memakai id DOM `album-*`, sehingga halaman baru memakai id `folder-*` dan JS bersama.
- Audit: vault_routes.py (/vault) menampilkan semua file; document_routes.py (/documents) sudah menyaring file_type='document' tetapi belum berfolder. Keduanya kini berbagi helper.
- Audit: base.html punya menu My Vault, Documents, Media Vault; upload memakai vault.upload.
- Fase 1 selesai: `routes/collection_shared.py` (helper nama/berkas/koleksi), `/musik` di collection_routes.py, Media hanya foto/video, unggah kategori musik divalidasi ekstensi audio, `static/js/collection_folders.js` + `static/js/musik.js`, CSS tambahan di akhir.
- Fase 1: pemutar HTML5 memakai `/media-vault/view` (Range) dan Winamp tetap lewat grant `media.winamp`; item terkunci memakai `media.stream`, folder terkunci `album.unlock`, item hidden tidak dimuat pada daftar biasa.
- Fase 2 selesai: /vault dan /documents memakai template folder yang sama; hanya file_type='document', folder kind='dokumen', pencarian/pengurutan klien `static/js/dokumen.js`.
- Fase 3 selesai: menu sidebar Dokumen, Media, Musik; tes baru test_n3b_musik_dokumen.py; tes media lama disesuaikan karena audio tidak lagi di halaman Media.
- Berkas diubah: modules/strings.py, routes/collection_shared.py (baru), routes/collection_routes.py, routes/media_routes.py, routes/vault_routes.py, routes/document_routes.py, templates/base.html, templates/media_vault.html, templates/musik.html (baru), templates/vault.html, static/js/collection_folders.js (baru), static/js/musik.js (baru), static/js/dokumen.js (baru), static/css/style.css, tests/test_n3b_musik_dokumen.py (baru), tests/test_media_routes.py.
- Belum diuji otomatis: interaksi peramban (pemutar audio, klik trek, pencarian/pengurutan langsung, modal grant).
- Uji manual: 1) buka Musik, unggah mp3, buat folder musik, pindahkan trek; 2) putar/jeda/berikutnya/sebelumnya dan Winamp bila terpasang; 3) kunci folder lalu buka dengan autentikasi ulang; 4) sembunyikan item lalu tampilkan lewat tombol Tersembunyi; 5) buka Dokumen, buat folder, pindahkan banyak dokumen, coba cari dan urutkan; 6) pastikan Media tidak menampilkan audio dan musik tidak muncul di Dokumen; 7) muat ulang halaman folder terkunci dan pastikan isi tidak ada di HTML.
