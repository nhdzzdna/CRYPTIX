# N1 - Kunci pemulihan, pendaftaran wajah, username tersamar

## Audit awal (sebelum perbaikan)
- N1-1: `static/js/script.js` menghapus semua elemen `.alert` setelah 5 detik
  (auto-dismiss). Kotak kunci pada `templates/recovery.html` memakai
  `class="alert alert-warning"`, sehingga kunci ikut hilang. Tidak ada meta
  refresh atau pengalihan otomatis lain; masalahnya murni auto-dismiss.
- N1-2: `static/js/face.js` rusak sintaksnya. Ada deklarasi
  `async function kirimPendaftaran(hasil, statusEl, grant) {` yang tidak
  ditutup, lalu fungsi bernama sama dideklarasikan ulang. Seluruh berkas gagal
  diurai, `window.CryptixFace` tidak pernah dibuat, dan klik tombol di
  `static/js/setup.js` tidak melakukan apa pun. Tombol memang tidak disabled.
- N1-3: `routes/account_routes.py` hanya memilih `site_name_enc` dan
  `updated_at`; `username_enc` tidak pernah didekripsi dan
  `templates/account_vault.html` tidak punya tempat username tersamar.

## Perbaikan
- N1-1: kotak kunci tidak lagi memakai `.alert`; tambah `static/js/recovery.js`
  (salin, unduh .txt via Blob, tombol lanjut baru aktif setelah dicentang).
- N1-2: perbaiki `face.js`, tambah petunjuk/indikator/progres, dan tegakkan
  ambang deteksi >=80% serta tolak lebih dari satu wajah di server.
- N1-3: tambah penyamar username server dan tampilkan di daftar Account Vault.
