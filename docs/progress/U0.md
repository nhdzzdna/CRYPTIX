# U0 - Fondasi Desain, Rename KOSYAK, Hapus Security Assistant

## Ringkasan

Sesi ini membangun fondasi antarmuka bersama (token warna, tipografi, komponen,
ikon, kerangka sidebar/topbar, dan komponen JavaScript), memindahkan rute audio
utama ke `/audio`, menghapus Security Assistant secara total, lalu mengganti teks
tampilan CRYPTIX menjadi KOSYAK.

Isi halaman lama tidak diubah pada sesi ini. Dokumen ini juga menjadi katalog
komponen yang dipakai sesi halaman berikutnya.

## Rencana Awal

1. Audit `templates/base.html`, `auth_base.html`, `static/css/style.css`,
   `static/js/script.js`, dan `app.py`.
2. Tambah token, CSS dasar, CSS komponen, font lokal, sprite ikon, dan makro ikon.
3. Bangun ulang kerangka sidebar/topbar dan toast flash.
4. Tambah komponen JavaScript di `static/js/ui/` dengan API global `KX`.
5. Pindahkan rute utama audio ke `/audio` dan arahkan `/musik` ke sana.
6. Hapus Security Assistant dari kode, rute, template, aset, string, dan tes.
7. Rename teks tampilan CRYPTIX menjadi KOSYAK tanpa menyentuh konstanta kripto.
8. Tambah/perbarui tes dan lengkapi katalog di dokumen ini.

## Keputusan

- Topbar hanya menampilkan judul dan badge sesi; tombol aksi lama di topbar
  tidak dirender sampai halaman masing-masing dimigrasikan.
- Badge sesi hanya menampilkan hitung mundur. Klik badge memuat ulang halaman,
  yang memperbarui tanda waktu sesi lewat mekanisme `login_required` yang ada.
- Font lokal dipakai bila berkas tersedia; jika tidak, tumpukan font sistem
  menjadi fallback.
