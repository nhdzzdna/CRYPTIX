# U0 - Fondasi Desain, Rename KOSYAK, Hapus Security Assistant

## Ringkasan

Sesi ini membangun fondasi antarmuka bersama (token warna, tipografi, komponen,
ikon, kerangka sidebar/topbar, dan komponen JavaScript), memindahkan rute audio
utama ke `/audio`, menghapus Security Assistant secara total, lalu mengganti teks
tampilan CRYPTIX menjadi KOSYAK.

Isi halaman lama tidak diubah pada sesi ini. Dokumen ini juga menjadi katalog
komponen yang dipakai sesi halaman berikutnya.

## Rencana Awal

1. Audit `templates/base.html`, `auth_base.html`, `static/css/style.css`,
   `static/js/script.js`, dan `app.py`.
2. Tambah token, CSS dasar, CSS komponen, font lokal, sprite ikon, dan makro ikon.
3. Bangun ulang kerangka sidebar/topbar dan toast flash.
4. Tambah komponen JavaScript di `static/js/ui/` dengan API global `KX`.
5. Pindahkan rute utama audio ke `/audio` dan arahkan `/musik` ke sana.
6. Hapus Security Assistant dari kode, rute, template, aset, string, dan tes.
7. Rename teks tampilan CRYPTIX menjadi KOSYAK tanpa menyentuh konstanta kripto.
8. Tambah/perbarui tes dan lengkapi katalog di dokumen ini.

## Keputusan

- Topbar hanya menampilkan judul dan badge sesi; tombol aksi lama di topbar
  tidak dirender sampai halaman masing-masing dimigrasikan.
- Badge sesi hanya menampilkan hitung mundur. Klik badge memuat ulang halaman,
  yang memperbarui tanda waktu sesi lewat mekanisme `login_required` yang ada.
  Belum ada endpoint perpanjang sesi khusus.
- Font lokal tersedia lengkap di `static/fonts/`; tumpukan font sistem tetap
  menjadi fallback. Tidak ada permintaan ke CDN.
- Halaman lama tetap memakai `static/css/style.css`; berkas itu tidak dihapus dan
  variabel lamanya dipetakan ke token `--kx-*` di akhir `tokens.css`.
- Rute internal audio tetap memakai blueprint/endpoint `collection.musik` agar
  `url_for` lama tidak putus; hanya URL publik dan label yang berubah.
- Penghapusan Security Assistant tidak menyentuh tabel berisi data pengguna.
  Tidak ada tabel khusus asisten pada skema saat ini.
- Rename KOSYAK hanya menyentuh teks tampilan. Nama internal yang dipertahankan:
  nama basis data `cryptix.db`, cookie/sesi, nama folder, header/magic kripto,
  label HKDF, AAD, `rp_name` WebAuthn, header HTTP internal `X-Cryptix-*`,
  awalan berkas sementara, serta namespace JS `Cryptix*`.
- Berkas font yang diharapkan: `PlusJakartaSans-VariableFont_wght.ttf`,
  `PlusJakartaSans-Italic-VariableFont_wght.ttf`,
  `SpaceGrotesk-VariableFont_wght.ttf`,
  `JetBrainsMono-VariableFont_wght.ttf`,
  `JetBrainsMono-Italic-VariableFont_wght.ttf`. Semuanya sudah ada.

## Keterbatasan

- Badge sesi tidak memperpanjang sesi di tempat; klik memuat ulang halaman.
- Halaman isi lama belum dimigrasikan ke komponen `kx-*`. Kerangka baru sudah
  berlaku, tetapi markup di dalam halaman masih memakai kelas lama.
- Komponen `kx-*` belum dipakai oleh halaman mana pun sehingga belum ada
  verifikasi visual otomatis; hanya diuji lewat keberadaan berkas dan kerangka.
- `meter-sandi.js` menghitung kekuatan secara lokal di peramban dan belum
  terhubung ke validasi server.
- `aksi-mengambang.js` hanya mengatur tampilan bar; aksi massal baru tersedia
  setelah halaman terkait memasang tombolnya.

  masih ada sebagai artefak lokal ter-ignore git. Tidak memengaruhi aplikasi.
- `docs/progress.md`, `docs/progress/` lama, `docs/baseline_test_results.txt`,
  dan `docs/desain/spesifikasi-ui.txt` masih menyebut Security Assistant/CRYPTIX
  sebagai catatan historis atau bahan desain; sengaja tidak diubah.
- CSP masih mengizinkan `fonts.googleapis.com` dan `fonts.gstatic.com`, tetapi
  tidak ada lagi permintaan font eksternal dari template baru. Pelonggaran CSP
  ini tidak diubah pada sesi ini.
- `docs/desain/spesifikasi-ui.txt` memuat menu Security Assistant dan pencarian
  global; kedua hal itu sengaja tidak diikuti sesuai ketentuan sesi ini.

## 5. API JavaScript `KX`

Semua berkas dimuat dari `base.html`; tidak ada skrip inline.

| API | Berkas | Keterangan |
|-----|--------|------------|
| `KX.toast(pesan, jenis, durasi)` | `ui/toast.js` | Jenis: `success`, `warning`, `danger`, `info`. Durasi bawaan 4000 ms. Alias `KX.notifikasi`. |
| `KX.modal.buka(el)`, `KX.modal.tutup(el)` | `ui/modal.js` | Esc menutup, fokus terjebak di dalam modal, fokus kembali ke elemen semula. |
| `KX.konfirmasiHapus({nama, onKonfirmasi})` | `ui/konfirmasi-hapus.js` | Dialog konfirmasi menyebut nama item; tombol hapus merah solid. |
| `KX.dropzone.init(el)`, `KX.dropzone.initSemua()`, `KX.dropzone.ukuran(bytes)` | `ui/dropzone.js` | Otomatis untuk `[data-kx-dropzone]`; menampilkan nama, ukuran, dan tombol hapus. |
| `KX.aksiMengambang.segarkan()`, `.terpilih()`, `.init()` | `ui/aksi-mengambang.js` | Otomatis untuk `[data-kx-pilih]` dan `.kx-aksi-mengambang`. |
| `KX.salin(teks, tombol)` | `ui/salin.js` | Otomatis untuk `[data-kx-salin]` dan `[data-kx-hash]`. |
| `KX.sandi.init()` | `ui/sandi.js` | Otomatis untuk `[data-kx-sandi]`; satu ikon mata: terbuka saat terlihat, dicoret saat tersembunyi. |
| `KX.meterSandi.init()`, `.hitung(nilai)` | `ui/meter-sandi.js` | Otomatis untuk `[data-kx-meter]`; 4 segmen: Lemah, Sedang, Kuat, Sangat kuat. |
| `KX.sesi.mulai()` | `ui/sesi.js` | Hitung mundur badge sesi. |

Toast dari flash dibaca dari `<div id="kx-flash" data-pesan='...'>`; berkas
`base.html` hanya menulis data, bukan skrip.

## 6. Aturan Template

- Ikon memakai makro `ikon()`; jangan menulis SVG inline di halaman.
- Item menu dibangun dari `modules/navigation.py`; endpoint yang belum terdaftar
  dilewati otomatis.
