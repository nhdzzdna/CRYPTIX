# N2 - Security Assistant lebih mengenali fitur CRYPTIX

## Audit awal
- Intent lama: security_status, encryption_advice, password_check, explain_log,
  feature_help, fallback. feature_help hanya punya 10 entri `_FEATURE_KB`;
  pertanyaan seperti "cara daftar akun" atau "apa itu mode pengembangan" jatuh ke fallback.
- Berkas: `modules/assistant/*.py`, `routes/assistant_routes.py`, `templates/assistant.html`, `static/js/assistant.js`, `tests/test_assistant*.py`.

## Perubahan
- Tambah `modules/assistant/knowledge.py`: 32 topik berisi kata kunci, sinonim,
  dan rujukan jawaban ke `MSG`.
- Tambah teks jawaban `ASSISTANT_KB_*` di akhir `modules/strings.py`.
- `_handle_feature_help` memakai basis pengetahuan lebih dulu; `classify_intent`
  mengarahkan pertanyaan yang tidak tertangkap pola lama ke feature_help.
- Penanda status (terdaftar/aktif/terpasang/integritas) dan pola log tetap
  diprioritaskan agar status keamanan dan ringkasan log tidak berubah.
- Asisten tetap rule-based, tanpa LLM atau jaringan. Kolom password terpisah,
  riwayat sisi server, dan status keamanan tidak diubah.

## Hasil
- Tes terarah 127 lulus (`test_n2_asisten`, `test_assistant`,
  `test_assistant_routes`); pytest penuh dijalankan sekali di akhir.
- Uji manual: (1) tanya "Bagaimana cara daftar akun?", "Apa itu WebAuthn?",
  "Bagaimana cara memulihkan akun?", dan "Apa itu mode pengembangan?";
  (2) pastikan "Apakah wajah saya terdaftar?" tetap menjawab status;
  (3) pastikan kolom password dan riwayat tetap memakai "[password diperiksa]".

## Temuan di luar lingkup
- README menyebut autentikasi sidik jari, tetapi UI hanya menyediakan wajah
  dan WebAuthn; tidak diubah.
