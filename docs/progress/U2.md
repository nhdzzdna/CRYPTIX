# U2 — Koleksi: Dokumen, Media, Audio, Sampah

## Bagian 1 — Dokumen (P4: Halaman Dokumen `/documents` & `/vault`)

### Ringkasan
Redesain antarmuka halaman Dokumen (`templates/vault.html` dan fallback `templates/documents.html`) menggunakan sistem desain KOSYAK:
- Komponen `kx-*` (kartu `kx-card`, form `kx-field`, dropzone `data-kx-dropzone`, tabel/daftar berkas `kx-doc-row`, aksi mengambang `kx-aksi-mengambang`, modal pratinjau `kx-modal-overlay`).
- Pemisahan CSS khusus halaman ke `static/css/halaman/documents.css` via `{% block styles %}`, tanpa mengubah `static/css/style.css`.
- Pemisahan interaksi JavaScript ke `static/js/documents.js`, tanpa JavaScript inline (memenuhi CSP ketat).
- Penambahan konstanta teks UI formal berbahasa Indonesia di `modules/strings.py` tanpa emoji dan tanpa duplikasi kunci.
- Tetap mempertahankan alur backend utuh: unggah enkripsi AES-256-GCM, unduh verifikasi grant `file.download`, pratinjau grant `doc.preview`, penguncian item/folder, pemindahan folder, dan soft-delete ke Sampah (`TRASH_MOVE`).

### Keputusan
1. **Dua Template**: Meskipun rute `/documents` mengarahkan render ke `vault.html`, template fallback `documents.html` tetap diredesain dengan komponen `kx-*` demi konsistensi kode dan dokumentasi.
2. **Intersepsi Hapus Lunak**: Tombol hapus individual diintersepsi di sisi klien menggunakan `KX.konfirmasiHapus` agar memunculkan modal dialog dengan menyebut nama berkas dan menjelaskan bahwa berkas dipindahkan ke Sampah, bukan langsung hapus permanen.
3. **Kompatibilitas Komponen Lama**: Kelas-kelas penanda seperti `doc-action`, `media-select`, `doc-file-row`, dan `[data-doc-item]` tetap dipertahankan bersamaan dengan kelas `kx-*` agar tidak merusak logika `collection_folders.js` dan `dokumen.js`.

### Keterbatasan
- Format berkas perkantoran (.docx, .xlsx, .pptx) tetap tidak mendukung pratinjau inline langsung di peramban (ditolak 415 oleh backend sesuai rancangan); hanya format teks, PDF, dan gambar yang dapat dipratinjau.
- Pengujian otomatis mencakup pemuatan komponen, pencegahan inline script, pemuatan berkas CSS, dan rendering item terkunci. Uji visual peramban interaktif (drag-and-drop manual) tetap memerlukan verifikasi peramban.

## Bagian 2 — Audio dan Pengunci Item Generik (P5: Halaman Audio `/audio` & `item_lock.js`)

### Ringkasan
Redesain antarmuka halaman Audio (`templates/musik.html` dan `static/js/musik.js`) serta modul pengunci item generik (`static/js/item_lock.js`):
- Komponen `kx-*` (kartu `kx-card`, tabel trek `kx-audio-table`, tombol play bulat `kx-audio-play-circle`, dropzone `kx-dropzone`, bar aksi mengambang `kx-aksi-mengambang`).
- Pemutar kustom tetap di bawah layar (bottom bar): cover placeholder, judul, folder, tombol prev/next, tombol play bulat teal, waktu berjalan, progress bar teal interaktif, dan total durasi. Halaman diberi padding bawah (`padding-bottom: 96px`) agar konten tidak tertimpa bar pemutar.
- Checkbox pilih semua di header tabel dan pencarian trek lokal di sisi klien yang memfilter baris tanpa reload.
- Menu titik tiga (⋯) per baris menyediakan aksi: Buka di Winamp (jika Winamp terpasang), Unduh, dan Hapus (ke Sampah via `KX.konfirmasiHapus`).
- Pengunci item generik di `static/js/item_lock.js` ditulis ulang menggunakan dialog berbasis `KX.modal` yang menerima scope fleksibel (`item.view`, `doc.preview`, `item.unlock`, `album.unlock`) dan resource id, mempertahankan event `cryptix:reauth-grant` dan alur reauth yang ada.

### Keputusan
1. **Durasi Teks '-'**: Spesifikasi UI meminta durasi mono ("tampilkan bila diketahui, kalau tidak '-'; jangan menambah backend"). Durasi default dirender sebagai '-' di template dan diperbarui di klien saat berkas dimuat pada audio player.
2. **Tag Audio Native Tersembunyi**: Tag `<audio id="music-audio" hidden>` dipertahankan di dalam template agar mesin pemutaran streaming audio HTML5 tetap berjalan tanpa merusak kompatibilitas `test_n3b_musik_dokumen.py` yang memeriksa `id="music-audio"`.
3. **Pengunci Item Generik**: Tetap mengekspos `window.CryptixLock` dengan API yang sama (`pilih`, `mintaGrant`, `lepasKunci`) agar tidak merusak pemanggil di `collection_folders.js`, `media_albums.js`, dan halaman Dokumen.

### Keterbatasan
- Format pemutaran di peramban bergantung pada kemampuan decoder audio browser pengguna (format standar MP3/WAV didukung luas, FLAC/OGG bergantung peramban).
- Durasi awal seluruh daftar lagu sebelum diputar tidak disimpan di database SQLite, sehingga kolom durasi tabel menampilkan tanda strip '-' sesuai ketentuan.
